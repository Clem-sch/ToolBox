# Assets

## Logo

Lege dein festes Logo hier ab:

- `logo/logo.png`
- oder `logo/logo.pdf`
- oder `logo/logo.jpg`
- oder `logo/logo.jpeg`

## Importierte Bilder

Das Skript kopiert Bilder aus `..\..\image_drop\` automatisch nach:

- `imported/`

Diese Bilder koennen dann in LaTeX ueber `\ImportBildFile` verwendet werden.
