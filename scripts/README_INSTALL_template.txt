CellSearchHub Local Package

Dieses Paket wird direkt aus dem entpackten Ordner verwendet.

1. ZIP entpacken.
2. install.ps1 im entpackten Ordner ausfuehren.
3. Danach CellSearchHub ueber Desktop, Startmenue oder direkt ueber CellSearchHub.exe starten.

Wichtig:
- Die EXE erwartet app.py, hub, bundled_tools, assets und outputs im gleichen entpackten Ordner.
- Es wird bewusst nichts nach %LOCALAPPDATA% kopiert.
- Alle Outputs bleiben lokal im entpackten Paketordner.
